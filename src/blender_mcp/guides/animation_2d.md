# 2D animation (Grease Pencil)

Tested on Blender 5.3 (marked [5.3]). Grease Pencil was rewritten in 4.3, so 3.6-4.2 use a
different API (marked [untested]). Always check which one the user's Blender has:
`lookup_api("GreasePencil")`. Timing basics are in `animation_3d`.

## When to use

Hand-drawn style animation, storyboards and animatics, 2D characters in a 3D scene, outline
(toon) rendering of 3D models with Line Art, animated diagrams and handwriting effects.

## Inputs needed

- Style: frame-by-frame drawing, cut-out (rigid parts moved with keys), or Line Art over 3D.
- Frame rate (2D is often animated "on twos": a new drawing every 2 frames at 24 fps) and
  length; canvas aspect.
- Line weight and palette; whether drawings come from the user (they draw, you set up) or
  are generated by script (simple shapes, text, diagrams).

## Workflow

1. Set up: fps, frame range, an orthographic camera facing the drawing plane (or a
   perspective camera for 2D-in-3D). Draw on the XZ plane (Blender front view) by default.
2. Create a Grease Pencil object with layers per part (`Lines`, `Fill`, `Characters`,
   `BG`), and stroke/fill materials.
3. Strokes: from the user's drawing, or by script (below) for shapes, paths and text.
4. Animate:
   - frame by frame: a new layer frame per drawing (on twos: frames 1, 3, 5 ...);
   - cut-out: separate GP objects or layers per part, animated with object/layer
     transforms and keyframes;
   - reveals: a Build modifier draws strokes on over time.
5. Effects with modifiers: Noise (boiling lines), Thickness, Tint, Outline, Time (offset
   or loop), Line Art for 3D-to-2D outlines.
6. Render with EEVEE; check frames with `look(mode="render")` at key frames.

## Tested values and code

```python
# [5.3] Grease Pencil v3 (4.3+): object type GREASEPENCIL, data bpy.data.grease_pencils
gp = bpy.data.grease_pencils.new("Sketch")  # 4.3 only: bpy.data.grease_pencils_v3
ob = bpy.data.objects.new("Sketch", gp)
collection.objects.link(ob)
mat = bpy.data.materials.new("Ink")
bpy.data.materials.create_gpencil_data(mat)
gp.materials.append(mat)
layer = gp.layers.new("Lines")
frame = layer.frames.new(1)  # frame_number 1
drawing = frame.drawing
drawing.add_strokes([4])  # one stroke with 4 points
for i, pt in enumerate(drawing.strokes[0].points):
    pt.position = (i * 0.2, 0, 0)
    pt.radius = 0.02
```

- Modifier types [5.3] are prefixed `GREASE_PENCIL_` (BUILD, NOISE, TINT, OPACITY, ARRAY,
  OFFSET, SIMPLIFY, SUBDIV, OUTLINE, TIME, LENGTH, ...) plus `LINEART`, and are added with
  `ob.modifiers.new(name, "GREASE_PENCIL_BUILD")`.
- Before 4.3 [untested]: object type `GPENCIL`, `bpy.data.grease_pencils.new()`,
  `layer.frames.new(n).strokes.new()` with `stroke.points.add(k)` and `point.co`, and
  modifiers in `ob.grease_pencil_modifiers` (types `GP_BUILD`, `GP_NOISE`, ...).
  Branch on `ob.type == "GREASEPENCIL"`.
- Point radius 0.005-0.03 m reads as ink at normal camera distances; Noise modifier factor
  0.1-0.3, step 2-4 frames for gentle line boil.
- Line Art: add a `LINEART` modifier to a GP object, `source_type` "SCENE", "COLLECTION" or
  "OBJECT"; it needs a camera and a GP material for its output.

## Common mistakes

- Using legacy GP code (`strokes.new`, `GPENCIL`, `grease_pencil_modifiers`) in 4.3+, or
  v3 code in older versions. Check the type first.
- Strokes without a material: invisible. Every GP object needs a GP material
  (`create_gpencil_data`).
- Drawing on the wrong plane relative to the camera: strokes seen edge-on disappear.
- Every frame a new drawing at 24 fps: too much work and jittery; animate on twos.
- Radius in pixels thinking: in v3 `radius` is in scene units.
- Changing the user's drawings by script: work on new layers unless asked.

## Verification checklist

- [ ] Object type and API branch match the user's Blender version.
- [ ] Each layer has frames where expected (`[f.frame_number for f in layer.frames]`).
- [ ] Strokes are visible from the camera at the first, middle and last frame
      (`look(mode="render")`; `look(mode="camera")` for quick checks).
- [ ] Line weight consistent; fills don't leak; modifiers render as intended.
- [ ] Timing feels right in a preview render the user can watch.

## Manual work and external tools

- Expressive drawing is hand work with a tablet in Draw mode: set up the canvas, layers,
  brushes and timing, then hand over to the user.
- Cleaning scanned drawings or vector art may be easier in Krita, Illustrator or Inkscape;
  import SVG with `bpy.ops.wm.grease_pencil_import_svg` (exists in [5.3]; arguments untested, check them with
  lookup_api).
- Brush presets and add-ons (e.g. extra GP tools) are installed by the user; safe execution
  mode refuses enabling add-ons, changing preferences and adding event handlers. Explain
  that and never bypass it.
